# Contributor Covenant Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

Be respectful and constructive. Harassment, discrimination and personal attacks
are not tolerated. Report unacceptable behavior to the maintainers through a
private report on GitHub; every report is reviewed and kept confidential.
